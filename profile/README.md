# SwaDeshiTech

We build developer-platform tooling that helps teams ship, operate, and scale applications on Kubernetes.

## What we build

- **[ProdHub](https://github.com/SwaDeshiTech/prodhub):** a platform for streamlining development and deployment workflows.
- **[ProdHub CLI](https://github.com/SwaDeshiTech/prodhub-cli):** terminal access to ProdHub for managing, deploying, and monitoring products.
- **[Environment Orchestrator](https://github.com/SwaDeshiTech/environment-orchestrator):** namespace-local discovery, DNS, and load-balancing services for Kubernetes.
- **[CI Captain](https://github.com/SwaDeshiTech/ci-captain):** unified CI orchestration across Jenkins and GitHub Actions.
- **[KubeSync](https://github.com/SwaDeshiTech/kubesync):** ConfigMap synchronization between Kubernetes namespaces.
